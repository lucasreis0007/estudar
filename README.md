# OpenMind — Passo 01

Projeto de estudos criado especificamente para o OpenMind.

**Importante:** este projeto NÃO contém páginas, scripts ou lógica do aplicativo de finanças original. A referência visual/estrutural do projeto antigo foi usada apenas como inspiração.

## Objetivo
PWA de estudos de Eletromecânica, com arquitetura expansível.

Matérias iniciais:
- Motores e tipos de partida
- Dimensionamento
- Manutenção preventiva e corretiva
- Processos de fabricação
- Usinagem
- Desenho técnico
- Elétrica predial
- Operação de torno
- Operação de fresadora

## Neste passo
- Base visual mobile-first
- Dashboard inicial
- Navegação de estudos
- Matérias tratadas como dados
- Português/English preparado
- PWA básico
- IA propositalmente DESATIVADA (entra no passo 12)
- Firebase reservado para integração com o projeto existente

## Próximos passos
A cada etapa será gerado um novo ZIP. O conteúdo de IA não será implementado antes do Passo 12.
